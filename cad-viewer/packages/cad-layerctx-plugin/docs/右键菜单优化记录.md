# 右键菜单优化记录

> 对象右键菜单插件 `@mlightcad/cad-layerctx-plugin` 的优化历史记录。
> 涉及文件：`src/layerCtxMenu.ts`、`src/layerCtxKeyHandler.ts`、`src/layerCtxHistory.ts`、`src/i18n.ts`、`src/AcApLayerCtxPlugin.ts`。

## 优化清单

### 1. 颜色随主题切换（修复）

**问题**：菜单样式引用 Element Plus 的 `--el-*` CSS 变量，但宿主是 Ant Design 壳、不提供这些变量，菜单永远落到硬编码的浅色兜底值，暗色主题下仍是白底。

**修复**：样式改为引用查看器主题令牌 `--ml-ui-*`（`acedApplyUiTheme` 每次切换主题都会刷新到 `documentElement`），并保留浅色兜底 + `html.dark` 块提供暗色兜底，两种宿主主题接入方式（`data-ml-ui-theme` / `html.dark`）都能正确跟随：

```css
.ml-layerctx-menu {
  --mlctx-bg: var(--ml-ui-bg, #ffffff);
  --mlctx-text: var(--ml-ui-text, #303133);
  /* ... */
}
html.dark .ml-layerctx-menu {
  --mlctx-bg: var(--ml-ui-bg, #1d1e1f);
  --mlctx-text: var(--ml-ui-text, #e5eaf3);
  /* ... */
}
```

### 2. 快捷键 AutoCAD 命令别名化

**前**：`Ctrl/Cmd+Shift+C/M/S/R/A/E` 组合键，繁琐且不符合 AutoCAD 习惯（AutoCAD 中 `Ctrl+Shift+C` 是"带基点复制"）。

**后**：单字母直接触发，与 AutoCAD 命令别名一致：

| 菜单项 | 快捷键 |
| --- | --- |
| 复制 | `C` |
| 移动 | `M` |
| 缩放 | `S` |
| 旋转 | `R` |
| 偏移 | `O` |
| 删除 | `E`（`Del` 由宿主处理，保持不变） |
| 取消选择 | `Esc`（与宿主清空选择语义一致） |

**防劫持**：焦点在任何 `INPUT`（含命令行）、`TEXTAREA`、可编辑元素时按键照常输入文本——命令行里敲 `M`+回车走正常的别名路径；多行文字编辑、命令取点期间也不劫持。菜单打开时这些字母同时充当访问键（按 `M` 即执行移动）。

### 3. 重复上次命令（Repeat Last Command）

AutoCAD 右键菜单的标志性首项。新增 `src/layerCtxHistory.ts` 监听宿主 `commandEnded` 事件：

- 菜单顶部显示 `Repeat <命令>`（如 `Repeat Move` / `重复 移动`），点击即重跑，走 `dispatchCtxCommand` 管线（变换类命令同样享受选择集恢复）；
- 写命令在只读文档 / 空选择时置灰（依据命令的 `mode >= Review` 判定）；
- 导航/UI 类命令（pan、zoom、undo、redo、regen、switchbg、open、qnew、log、quit、exit）不进入重复记录；
- 已知命令显示本地化名称（copy/move/rotate/layctxscale/layctxoffset/layctxdel/erase），其余显示命令名。

### 4. 无选中时的导航菜单

**前**：空画布右键什么都不弹。**后**：弹 AutoCAD 式导航菜单——重复上次命令 + 平移（宿主 `pan`）+ 视图缩放（宿主 `zoom`：回车=范围缩放、两角点=窗口缩放）。有选中时仍弹带"已选中 N 个对象"标题的对象菜单。

### 5. 访问键助记符下划线

菜单标签中与快捷键一致的字母带下划线（`<u>C</u>opy`、`<u>M</u>ove`…），AutoCAD 助记符风格；标签中不含该字母的语言（如中文）靠右侧快捷键提示展示。

### 6. 悬停与焦点同步

菜单项 `pointerenter` 时同步移动焦点，避免键盘高亮与鼠标悬停高亮同时出现在两个条目上。

### 7. 菜单宽度动态化

**前**：`min-width: 200px` 固定下限，中文等短文案下菜单明显过宽。

**后**：`width: max-content` 随内容自适应（由最长条目决定宽度），`max-width: 320px` 保留为上限防超长内容溢出。

## 验证

- 插件构建：`tsc` + `vite build` + `eslint` 全部通过；
- e2e（Playwright，Chromium）：`e2e/tests/layerctx-menu.spec.ts` 5/5 通过，覆盖：菜单结构/键盘导航/下划线/动态宽度、单键快捷键与输入框防劫持、重复上次命令与导航菜单、主题颜色切换、缩放预览；依赖右键菜单的 `layer-select-selection.spec.ts`、`property-bar-selection.spec.ts` 6/6 通过。

## e2e 调试要点（记录于此避免重复踩坑）

- `waitForPickableLine` 轮询必须以**对象菜单标题**（`Selected: N`）作为"拾取成功"标志——导航菜单也会打开，会误判提前返回；
- 每轮轮询都要按 `Esc` 关掉菜单再右键：菜单定位在光标处，下一轮右键会点在打开的菜单上被忽略，轮询将死锁直至超时；
- 颜色测试改用空白角右键弹导航菜单取色（与对象菜单共用同一套主题变量），不依赖实体拾取，避免并行 worker 下 WebGL 软渲染竞争导致的超时；
- 画布 mousedown 被宿主 `preventDefault`，点击画布不会使命令行失焦——测试中需显式 `blur()`。
