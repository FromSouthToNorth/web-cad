本阶段主线：**UI 框架 Element Plus → Ant Design Vue 的彻底迁移与 AutoCAD 风格 Ribbon 重构**、**绘制巷道等业务功能插件化落地**、**大图纸性能战役的收官（A1-A4 / B1-B3）**、以及 CAD Agent 稳定性修复与工程化治理。

## 一、界面与交互重构

- **组件库迁移**：UI 组件库由 Element Plus 整体迁移至 Ant Design Vue（9/2）；旧壳先拆到 `/legacy` 子路径（9/3），随后连同子路径一起删除，`element-plus` 完全退出依赖（9/3）。
- **Ribbon 工具栏**：AutoCAD 风格 Ribbon 工具栏重构（9/2），随后精简为两行布局并重排面板控件（9/2）；功能区按 Ant Design 与 AutoCAD 交互规范改造（9/4）：Alt 键提示导航、折叠过渡动画、SuperTip 增强提示、禁用态修复、图标尺寸与无障碍对齐。
- **图层面板**：图层右键菜单历史记录与属性栏增强（9/4）；右键菜单宽度随内容自适应（9/4）；图层快速选择器重构（9/4）。
- **主题**：Steel Blue 主题配色 + 提取 `--ml-theme-*` CSS 变量（8/28）；明暗主题切换联动 `MODELBKCOLOR` 画布背景（暗色黑底/亮色白底），头部页脚毛玻璃效果（8/25）。
- **移动端**：触控适配、渲染降级、响应式布局（9/5，FromSouthToNorth）。
- **示例壳**：样式按 Ant Design 规范优化（9/3）；示例默认新建图纸（8/20）；dev server 固定 5173 端口（8/24）。

## 二、业务功能

- **绘制巷道（本阶段最大功能）**：隧道插件（`cad-tunnel-plugin`）+ 自定义实体基础设施 + 面板实时应用 + 宽度渲染落地（9/7）；新增示例数据 `jsonData/tunnel.json`（9/7）；读取巷道改名、加载动画与立井符号 `transformBy` 修复（9/8）。
- **插件化**：内容搜索面板插件（`cad-search-plugin`）+ 反选功能插件化（`cad-invertsel-plugin`）（8/27）；新增图层上下文插件 `cad-layerctx-plugin` 并扩展命令与国际化条目（8/28）。
- **反选**：`INVERTSEL` 反选命令 + Ribbon 按钮 + `Ctrl/Cmd+Shift+I` 快捷键（8/25）。
- **MTEXT 打散**：MTEXT 打散为 TEXT + 居中对齐偏移修复（8/26）；样式拉宽修复 + Unicode 上标/下标转换（8/26）。
- **选择高亮**：新增选择顶点标记与批处理虚线高亮（8/19）；框选选中对象日志打印与大量数据选择/标记性能优化（8/20）；`GRIPSIZE` 默认夹点大小统一调整为 14px（8/21）。
- **国际化**：默认语言改为中文，FileUpload 上传页接入国际化（8/19）。
- **字体**：hztxt 中文字体支持（9/2）。

## 三、性能优化

- **框选/删除**：框选大量对象删除性能优化，修复卡顿崩溃（8/20）。
- **里程碑落地**：M3/M4/M5 优化落地（8/21）；P0 圆/弧密度零对象化（`getPointsFlat` 位级等价 + flat 构建器 + 巨型弧回退）、P2 drain 阈值裁剪消除全量拷贝（8/24）；P3 `splitLineSegmentsClusters` 预分配 TypedArray 共享缓冲零拷贝、P5 关键字大写零分配（8/24）。
- **性能小项收官**：解析侧 A1-A4 + 渲染侧 B1-B3 实施计划落地（9/7）。
- **渲染**：圆弧 LOD 渲染（9/4）。
- 以上优化均附全量回归与基准记录，相关分析见 `docs/02-性能优化/`。

## 四、缺陷修复

- **CAD Agent**：修复第二轮会话报错（历史中非法工具调用部件导致校验失败，9/3）；修复多轮对话报错（空图纸 extents 为 Infinity 导致模型消息校验失败，9/3）。
- **启动稳定性**：修复属性栏在引擎初始化前挂载导致的启动崩溃（9/2）；修复 Agent/Search 插件懒加载在应用二次打包后崩溃的问题（9/2）。
- **DXF 清洗**：文字对齐偏移修复（位置保持 + 清除组码 11 残留）（8/21）。
- **数据模型**：缺失颜色组码默认 ByLayer 修复（9/4）。

## 五、架构与依赖治理

- 移除 GPL 协议的 `libredwg-converter`，仅保留 MIT 协议的 DXF 解析链路（9/1）。
- 移除 `cad-simple-viewer-example` 并清理相关配置（8/28）、残留引用与死链（9/1）。
- 移除 DeepSeek VL 服务商，视觉模型统一由 DeepSeek 提供（9/2）。
- 本地 realdwg 依赖切换为 `file:` 覆盖（8/20）；cad-viewer 与 realdwg-web 以普通目录 vendor 进仓库（8/18，紧邻本阶段起点，一并说明）。

## 六、工程化与文档

- **CI**：新增 GitHub Pages 自动部署 workflow（9/1）。
- **工具链**：DXF 清洗脚本迁移入 `cad-tools` 纳入 git（8/21）；`cad-tools` 增补 `--max-size`/`--skip-processed` 与图例裁剪/挂起复现工具（8/24）；重建 bench 基准工具链并同步性能优化文档（9/3）。
- **文档**：高性能技术分析报告（WASM/Worker/SharedArrayBuffer/内存管理，8/19）；Claude Code 工作指引 `CLAUDE.md`（9/3）；隧道插件设计文档补充自定义绘制对象继承关系 Mermaid 类图（9/7）；另有多篇缺陷修复总结与 08-21～08-23 夜间回归记录。
