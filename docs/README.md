# 项目文档索引

## 目录结构

```
docs/
├── 01-架构设计/         # 整体架构、关键流程、技术选型分析

├── 03-缺陷修复与功能改造/  # 具体 bug 修复与功能改造的总结
├── 04-开发规范/         # 插件开发标准等公共规范
├── 05-使用手册/         # 面向使用者的参考手册
├── 06-工具脚本/         # 数据预处理工具的逻辑分析
└── README.md            # 本索引
```
